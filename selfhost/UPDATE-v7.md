# v7: 本地音量检测与录音回放

## 使用方法

使用可信 HTTPS 打开网页，展开“语音不能用？检查设备与权限”，点击“检查麦克风权限”。同意后允许麦克风权限，说一句话，观察实时音量，最多 8 秒后自动停止。也可提前停止，点击音频播放按钮回听。

- 录音仅在当前页面内存中，不上传、不持久化、不自动转文字。
- 清除录音、关闭检查面板、切换后台或离开页面会释放录音。
- 录音测试与浏览器语音识别不能同时启动。
- 音量有信号不等于有人声；回放清楚但问题框无文字，仍可能是浏览器识别服务网络不可用。
- 某些浏览器不支持 MediaRecorder 或 AudioContext；界面会提示对应限制。检测接口存在不代表真机已验证。
- 支持优先选择 WebM/Opus、MP4 或浏览器默认录音格式。音频格式最终兼容性需 OPPO / 一加及 Safari 真机测试。
- 暂未接入服务端语音转文字。应急办法：点击问题框，使用手机输入法语音输入。

## 部署注意

使用本次生成的 live-coach-selfhost.tar.gz。替换应用文件后重新构建并启动 web 服务。保留服务器 .env、compose.yaml 和 script-data 数据卷；本次不新增密钥配置。不覆盖 HTTPS 配置，不执行 docker compose down -v。

应用版本应显示 v7。浏览器刷新后检查；旧版缓存可通过关闭网页重新打开排查。

HTTPS IP 短期证书需要自动续期。此前证书到期时间为 2026-11-17；本次应用更新不包含服务器证书续期任务，请另行确认 Certbot 定时续期和 Nginx 重载已设置。
