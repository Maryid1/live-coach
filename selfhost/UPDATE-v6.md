# v6：手机触控与语音诊断

目标设备：OPPO／一加自带浏览器、苹果 Safari（手机/平板）。实际浏览器版本和设备权限仍需真机验证，桌面模拟不能替代真机。

新增语音诊断面板，区分 HTTP、安全上下文、浏览器识别接口、权限拒绝、网络失败、无语音和设备占用。HTTPS 下可经确认打开麦克风做最多 8 秒权限测试；不录制、不上传、不做音量分析、不代表已经识别出文字。停止、收起面板、切后台或离开页面后释放资源。识别和提词在切后台时暂停。

手机/平板输入字号至少 16px、主要触控目标至少 44px；加入安全区域适配、工具栏换行，手机生成答法后定位提词区域。保留稿件库、暖场和既有 AI 服务。


## HTTPS 与语音的待办

现有 HTTP+IP 不允许网页麦克风访问。本次不会绕过浏览器限制，也没有更换用户访问地址。不能仅部署 v6 就期待 HTTP 收音成功。

推荐维护者在现有 Node 服务前增加 HTTPS 反向代理，使用浏览器信任的证书，代理到应用的 3000 端口；保留原始 Host，确保同源 API 校验正常。需先确认可用域名及备案/服务商要求，或评估支持公网 IP 的证书和自动续期方案，不能直接给 IP 套普通域名证书。不要在手机上关闭证书校验。

HTTPS 完成后，分别在 Safari 与 OPPO／一加浏览器测试麦克风权限。若权限测试通过但识别服务失败，则需要另接服务端语音转文字及浏览器录音格式适配；当前没有这个服务，也没有新增付费调用。可暂用手机输入法语音输入。

## 真机验收

检查竖屏、横屏、弹出键盘、专注提词、长标题、Word/TXT 导入。HTTPS 后确认允许/拒绝麦克风的提示、识别网络失败、直播占用麦克风和切后台的表现。同一手机直播与助播不能保证同时收音，优先分设备。
