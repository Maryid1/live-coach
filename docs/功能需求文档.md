# 在场 · 健身直播助播台

功能需求文档 v1.0 · 2026-11-05

## 1. 项目目标

为健身工作室真人主播提供网页端助播，减少不知道说什么、怕回答不准确、冷场和忘记出镜注意事项的压力。主播自己判断、自己说话，系统辅助组织表达，不代替主播，也不承诺提升流量或保证平台审核通过。

首期支持小红书、抖音、视频号的助播场景，允许增加其他平台。这里的“支持”指选择平台、展示规则入口与提醒、把平台信息传给问答服务，不代表获得平台官方认证、读取弹幕、自动开播或同步推流。

## 2. 使用者与场景

- 主播：使用大字提词，口述或输入观众问题，选择简短、解释或互动版本。
- 场外助播（如家属）：协助填写工作室真实资料、整理问题、切换话题与提醒。v1 同一页面操作，不提供跨设备协同。
- 管理员：配置服务端 AI 凭据、支持联网搜索的模型、部署访问权限。

### 典型流程

1. 开播前填写工作室名称、教练称呼、区域、服务人群和已确认的课程信息。
2. 选择本场一个或多个平台，打开规则入口，在实际账号后台核对权限与最新要求。
3. 完成镜头、服装、收音、隐私和宣传信息检查，启动助播计时；另行在平台开播。
4. 有问题时输入文字，或主动授权浏览器语音识别，确认识别文本后获取三个答法。
5. 选择适合的版本，必要时编辑读稿，查看风险提示，再由真人口述。
6. 无互动时选择暖场话题与篇幅，载入提词区，手动启用滚动。
7. 定时查看状态提醒。结束助播停止计时；在平台单独结束直播。

## 3. 首期范围与依赖

| 模块 | 首期交付范围 | 边界 / 依赖 |
| --- | --- | --- |
| 多平台 | 三个预置平台、可多选、至少保留一个；最多新增九个平台 | 用户自定义信息不自动变成已核实规则 |
| 文字问答 | 手工输入、常见问题快捷填入、三种表达切换 | 离线模式是有限主题模板，不是任意问题的智能回答 |
| 语音输入 | 单次点击启动/停止识别，结果先填入输入框 | 浏览器 API、麦克风权限、网络和浏览器服务可用性；失败可打字 |
| 联网问答 | 服务端请求、搜索引用、响应验证、错误与超时处理 | 需配置密钥与支持搜索的模型；没有凭据时明确不可用 |
| 暖场稿 | 六类内置主题、短/长稿、工作室资料拼接 | 不虚构资质、案例、价格；任意主题 AI 暖场属后续扩展 |
| 提词 | 大字显示、字号、速度、滚动/暂停、专注模式、复制、编辑 | 不语音播放，不把录音当直播 |
| 风险自查 | 内置风险表达匹配、自定义词、原因与修改建议 | 仅当前提词文本；不是语义全检，也不持续监听口播 |
| 状态提醒 | 开播清单、可配置间隔、人工切换提醒 | 非摄像头识别，不生成形象评分 |
| 资料设置 | 浏览器本地保存、刷新恢复、所选平台与关注词配置 | 不跨设备；不存储密钥、录音和病历 |
| 问题历史 | 最近十条会话内结果，可重新载入 | 刷新清空，不上传数据库 |

## 4. 功能规格与验收条件

### F01 多平台与扩展

- 可单选/多选；默认小红书；无法取消最后一个平台。
- 每个平台包含稳定 ID、名称、显示标识、HTTPS 来源链接、补充提醒、核对状态。
- 新平台不需要修改问答或提词组件；通过“扩展一个平台”新增并保存。
- 不接受空名称、同名平台、不安全 URL 或超过数量限制的新增。
- 问答生成时固定本次平台上下文，避免请求中途切换导致答案语境混淆。
- 选择平台后能看到对应提醒。规则文案必须显示“待核对”而非假称实时更新。

### F02 问题输入与三个答法

- 问题 1–1500 字；空输入明确提示；快捷问题只填入，不擅自调用收费服务。
- 三个答法分别为简短接话、展开解释、互动追问；点击可替换提词内容。
- 语音不常驻监听；用户确认可能通过浏览器在线服务处理后启动，识别完成不自动发送 AI。
- 浏览器不支持、拒绝权限、识别失败或网络错误时，文字输入始终可用。
- 内置话术显示模式标签。不能回答的题目使用澄清和核实话术，不假装已了解答案。
- 涉及疼痛、病症、术后等问题采用专业评估边界话术；关键词分流不是医学判断。

### F03 AI 联网回答

- 管理员在服务端配置 `OPENAI_API_KEY`、`OPENAI_MODEL`；网页只接收配置状态，不接收密钥。
- 用户选择联网模式，并确认发送问题、平台名称、工作室资料；不向该接口上传录音。
- 服务请求搜索工具，校验搜索完成状态、引用 URL、三个回答的结构与长度。
- 引用来自服务返回的引用元数据，不使用模型任意编写的 URL 充当已检索证据。
- 只有成功获得可核对引用才展示为联网草稿。引用存在并不等于已经人工事实核验。
- 搜索失败、超时、限额、输出不完整、无来源均保留原读稿，给出错误，不偷偷降级成伪联网答案。
- 健康边界分流可能直接返回非联网提醒，必须显示真实模式。
- 需要联调的发布门槛：有效账号与额度、模型搜索能力、真实健康/课程/平台问题、中文引用与错误恢复测试。

### F04 暖场与提词

- 主题：新手首次到店、一周练几次、认识工作室、训练前沟通、体验课、温柔收尾。
- 支持预览短/展开稿；载入后跳到工作台，停止旧滚动并回到稿首。
- 字号 22–60 px，滚动速度 10–60 px/s，滚到底自动停；支持暂停与重新开始。
- 专注模式隐藏干扰；Esc 退出专注并暂停滚动。
- 编辑内容后立即重新检查风险。复制失败给出手动复制提示。
- 更换稿件应清楚标明稿件来源，不能把旧问答的引用冒用为暖场稿依据。

### F05 风险与规则

- 内置匹配关注：效果保证、诊疗承诺、绝对化比较/资质、需核对的引流交易表述、身体羞辱。
- 结果包含命中文本、风险原因、改写方向；不得称“命中即违规”或“未命中即合规”。
- 否定/引用语境也可能被提示，用户需结合上下文判断，不做机械词汇替换。
- 自定义关注词可一行一个或逗号分隔。v1 为全局词库；后续可扩展成分平台规则集。
- 官方规则链接、整理日期、是否实际核对正文必须可区分。不能编造平台内部处罚阈值。
- 初始来源入口在 2026-11-04 整理；部分正文读取受限，均保留待核对状态。

### F06 出镜、状态与计时

- 开播清单涵盖画面、服装、收音、客户隐私、宣传信息与平台规则；全部确认后启动计时。
- “开始助播”不等于平台开播，“结束助播”不等于平台下播。
- 以经过时间计时，不依赖 interval 回调次数；刷新不自动恢复直播状态。
- 每 1/3/5/10 分钟轮换轻提醒；不播放提醒声音干扰直播。
- 形象图为示意，不使用摄像头，不能声称自动识别了低头、衣着或疲劳。

### F07 工作室资料与本地存储

- 门店名、教练称呼、城市每项最长 100 字，目标人群 300 字，课程说明 1000 字。
- 不要求填价格；未填时不生成虚构优惠。用户提供的事实不代表系统独立验证。
- 显式保存到 localStorage；存储失败时保留本次操作并提示。
- 不储存客户身份、身体数据、病历；AI 密钥不得出现在浏览器存储或前端源码。
- 同一浏览器可查看保存资料，使用共用电脑时应自行清理站点数据；后续增加一键清理和导出。

## 5. 页面与视觉设计

- 临时产品名“在场”：强调真人表达与陪伴，不是自动代播。
- 风格：暖白底、苔绿色操作色、浅鼠尾草卡片、少量琥珀色风险提示。避免炫目动画和高压红色警报。
- 大屏：左导航 + 提问/暖场入口 + 大字答案提词 + 状态/风险栏。
- 小屏：单列内容、底部四个导航；不要求手机与电脑同时登录协同。
- 功能页：直播工作台、暖场话术库、平台与风险、工作室设置。
- 汉字界面使用本机中文字体；提词与标题使用楷体/宋体作为优先风格，无外部字体依赖。
- 键盘焦点可见、输入有标签、提示使用 live region、减少动态效果偏好生效。

## 6. 技术设计

采用 React + TypeScript + Vinext，保留 Sites/Cloudflare Workers 运行时集成。

```text
app/coach-app.tsx       页面与交互状态
app/coach.css           响应式视觉样式
lib/coach.ts           平台配置、内置话术、暖场、风险规则
app/api/assist/route.ts 服务配置状态、服务端联网问答
docs/                  需求与验收记录
tests/                 可复现的逻辑测试
```

数据流：问题文字 → 用户确认 → 本地模板或服务器 `/api/assist` → 三个答法与引用 → 人工选择/编辑 → 本地风险提示 → 真人口述。

服务端设置请求来源检查、JSON 类型/长度验证、Zod 结构校验、固定上游地址、超时、禁止存储响应选项。第三方服务仍遵守其自身的数据政策，不能宣称完全零留存。

初期部署应保持 owner-private。若扩大为多人或公共使用，必须先补齐用户身份授权、分布式限流、额度控制和日志脱敏，不应仅依赖网页按钮禁用。

## 7. 不在首期范围

- 三平台弹幕采集、登录接管、自动回复、推流、无人直播。
- 持续麦克风监听、实时打断违规口播、自动摄像头形象评分。
- 完整或永久有效的平台禁词库、保证过审、规避审核的谐音替词。
- 云端资料库、跨设备同步、多人协作、账号管理后台。
- 自动定时抓取规则更新、主动提醒平台规则变更。
- 任意主题 AI 暖场写作、语音合成、自动课程成交。

## 8. 后续迭代建议

1. 完成选定 AI 服务的真实联网联调，测量响应时长、拒答与来源质量；选择在使用地区可正常访问的服务。
2. 将全局关注词升级为带平台、来源、生效日期、审核人、版本和例外语境的规则集。
3. 增加工作室自有资料库、已审核话术收藏与跨设备同步，并完善权限。
4. 用户明确选择后，再增加摄像头本地预览/构图检测；先说明隐私与误报边界。
5. 仅通过平台允许的接口扩展弹幕接入，不把通用网页误称为已经对接所有平台。
