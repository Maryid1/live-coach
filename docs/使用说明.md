# 使用说明

## 打开网页

本项目支持本地运行和自部署。以下地址用于开发电脑；公开源码不提供私人测试站地址或账号。服务器部署参见《公开部署说明.md》。

1. 双击项目目录中的 `启动助播.cmd`。
2. 等待窗口出现 `Local: http://127.0.0.1:5173/`。如果端口被其他程序占用，以窗口实际显示的地址为准。
3. 在本机浏览器打开该地址。使用期间保留启动窗口，结束后 Ctrl+C 停止。

也可以在项目目录运行 `npm run dev -- --hostname 127.0.0.1`。

这个地址只在当前电脑使用，手机不能直接访问电脑的 `127.0.0.1`。页面已适配手机尺寸，但跨设备访问需要完成部署或额外配置安全网络访问。

## 第一次使用

1. 打开“工作室设置”，填写真实资料并保存。没有确定的价格、资质和优惠请留空。
2. 勾选本场平台。开播前进入“平台与风险”，在实际账号后台核对官方要求。
3. 点击“开始助播”，完成检查清单。这只开始计时，不会替你开播。
4. 填写或读出问题，确认文字后点击获取答法，挑一个适合自己的版本。
5. 点击“暖场话术库”，选主题和长短，放入提词区。读稿可展开编辑，支持调节字号、滚动速度和专注模式。
6. 风险提示只检查当前读稿。没命中不代表合规；真实说出口的内容不会自动被检测。

## 当前可用与不可用

- 可用：三平台选择与新增、内置三种答法、六类暖场稿、大字提词、风险关注词、定时提醒、开播清单、浏览器本地设置。
- 语音输入：浏览器提供单次语音识别时可用，需麦克风授权和相关服务可访问。真实麦克风识别尚需用户现场测试。
- AI 联网：已预留服务端接口，但未配置密钥和模型，当前不可用。关闭联网时是模板匹配，不是通用 AI。
- 未接入：平台弹幕、推流、摄像头识别、实时口播监听、多人跨设备协同。

## 隐私

门店资料、平台配置和关注词只在当前浏览器保存。共用电脑上的其他使用者也可能看到，清理浏览器站点数据可删除。会话问答不写入本地存储，刷新后消失。

语音识别可能经浏览器厂商的在线服务处理。不要读出客户姓名、电话、病历。AI 联网配置完成后，仅在用户主动请求并确认时发送问题、平台及门店资料给服务商。

## 管理员接入说明

密钥必须配置在服务端。示例变量名见 `.env.example`；生产环境通过 Sites 的运行时秘密配置，不要填写在工作室资料、问题输入框、前端环境变量或托管清单。

接入需要支持搜索的模型、账号权限和额度。当前实现对接 OpenAI Responses API；如果使用其他服务商，应实现独立适配层并重新测试搜索、引用、错误与安全分流，不只是换个接口地址。

联网回答不因为有引用就自动成为事实，主播仍需核对。公开分享前需补充身份授权、限流和费用控制。当前站点身份保留为私有，未发布。

## 验证命令

```text
node --test tests/coach.test.mjs
node node_modules/typescript/bin/tsc --noEmit
node --test tests/api.test.mjs
npm exec --yes --package=playwright -- node tests/browser.mjs
```

接口与浏览器测试需要先启动本地服务；浏览器测试使用无头 Edge，不启用麦克风或摄像头。生产构建使用 Sites 提供的 `scripts/build-site.mjs` 辅助工具。
